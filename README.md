# 小说平台 - 完整功能版

## 📋 项目概述

这是一个完整的小说平台，包含：
- **超级宏大官网首页**：轮播图、分类导航、书籍网格、排行榜
- **用户认证系统**：邮箱注册/登录、腾讯云验证码、忘记密码
- **支付系统**：书币充值、会员开通、个人支付宝收款码
- **阅读器**：字体大小调整、字体类型、6种主题、目录面板
- **真实小说内容**：6本热门小说（斗破苍穹、完美世界等），每章2000-4000字
- **爬虫系统**：定时爬取、多书源支持
- **社区功能**：圈子、社区讨论、帖子
- **创作者中心**：作家入驻、作品管理
- **完整协议**：用户协议、隐私政策、社区规范

## 🚀 一键部署指南

### 方法一：部署到 Railway（推荐）

#### 1. 准备工作

确保你有：
- GitHub账号
- Railway账号（免费额度可用）

#### 2. 点击部署按钮

```
访问 https://railway.app/new
选择 "Deploy from GitHub repo"
选择你的仓库
```

#### 3. 配置环境变量

在 Railway 控制台添加以下环境变量：

```env
# 腾讯云验证码（可选，已有默认值）
CAPTCHA_APP_ID=192339751
CAPTCHA_SECRET_KEY=4inhWL7rtPiyS1QU5IqnLlv86

# 邮件服务（可选）
# BREVO_API_KEY=你的Brevo密钥
# BREVO_SENDER_EMAIL=你的发送邮箱
```

#### 4. 部署完成！

Railway 会自动：
- 检测 Node.js 项目
- 安装依赖
- 启动 `npm start`
- 分配公网域名

---

### 方法二：本地部署

#### 1. 安装依赖

```bash
cd /workspace
npm install
```

#### 2. 启动服务

```bash
npm start
```

服务将运行在 http://localhost:3000

#### 3. 上传收款码

访问 http://localhost:3000/upload.html 上传你的支付宝收款码

## 🌟 功能特性详解

### 1. 宏大官网首页
- 顶部导航：用户协议、隐私政策、联系我们
- 轮播图：展示平台统计数据
- 分类导航：玄幻、仙侠、都市、历史、游戏、悬疑、科幻、言情等
- 书籍网格：热门推荐、新书上架
- 排行榜：热门榜、收藏榜、畅销榜
- 底部信息：关于我们、帮助中心、作家服务、法律声明

### 2. 阅读器
- 字体大小：小(16px)、中(18px)、大(20px)、特大(24px)
- 字体类型：宋体、黑体、楷体
- 阅读主题：6种（默认护眼色、纯白、深色、护眼绿、淡黄、粉色）
- 目录面板：显示章节列表、免费/付费状态
- 返回按钮：一键回到首页

### 3. 协议系统
- 用户协议：9个章节，十万字级内容
- 隐私政策：5个章节
- 社区规范：4个章节
- 协议跳转：所有页面底部都有链接

### 4. 支付系统
- 书币充值：多种面额（1元=100书币）
- 会员开通：月卡、季卡、半年卡、年卡
- 支付宝收款码：手动审核模式
- 订单查询：随时查看订单状态

### 5. 爬虫系统
- 启动时自动爬取初始数据
- 每小时定时爬取1-2页（分散负载）
- 支持多书源：笔趣阁、起点中文网镜像

## 🔌 核心API接口

### 书籍相关
```
GET /api/books/list              # 获取书籍列表
GET /api/books/:id               # 获取书籍详情
GET /api/books/:id/chapters      # 获取章节列表
GET /api/books/:id/chapters/:chapterId  # 获取章节内容
```

### 认证相关
```
POST /api/auth/register          # 注册
POST /api/auth/login             # 登录
POST /api/auth/send-code         # 发送验证码
POST /api/auth/forgot-password   # 忘记密码
POST /api/auth/reset-password    # 重置密码
GET  /api/auth/users             # 获取用户信息
```

### 支付相关
```
POST /api/alipay/submit-review   # 提交支付审核
GET  /api/alipay/orders          # 获取订单列表
POST /api/admin/orders/approve   # 审核通过订单
```

### 爬虫相关
```
POST /api/crawler/start          # 手动启动爬虫
```

## 💡 常见问题

### Q: 如何更新协议内容？
A: 编辑 `/data/agreements.json` 文件

### Q: 如何添加更多小说？
A: 编辑 `/db/init-books.js` 或使用爬虫自动爬取

### Q: 收款码在哪里上传？
A: 访问 `/upload.html` 页面上传

### Q: 如何手动启动爬虫？
A: 调用 `POST /api/crawler/start` 接口
